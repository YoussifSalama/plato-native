# Provider decisions: six guest-form ATSs (2026-10-23)

**Policy: `FILL_ONLY`** for SmartRecruiters, BambooHR, Recruitee, Teamtailor, Personio, JazzHR. Owner asked on 2026-10-23 for "10 platforms the extension can auto-apply on" (4 existing + 6 of the developer's choice). Picked for: public application form, no account needed, frequent as the apply target of board listings (Dice, Glassdoor, Google Jobs). Not picked: Workday and iCIMS (login + iframes), Rippling / Jobvite / Breezy kept as alternates.

| Platform | Scope (content script) | Form pages | Auto-submit |
|---|---|---|---|
| SmartRecruiters | jobs.smartrecruiters.com | `/<Company>/<id>-<slug>` listing → `/oneclick-ui/company/<Company>/publication/<id>` form | yes (opt-in per run) |
| BambooHR | *.bamboohr.com/careers | `/careers/<id>` → `/careers/<id>/apply` | yes (opt-in per run) |
| Recruitee | *.recruitee.com/o | `/o/<slug>` → `/o/<slug>/c/new` | yes (opt-in per run) |
| Teamtailor | *.teamtailor.com/jobs | `/jobs/<id>-<slug>` → `/jobs/<id>-<slug>/applications/new` | yes (opt-in per run) |
| Personio | *.jobs.personio.com/job, *.jobs.personio.de/job | `/job/<id>` (form on the page) | yes (opt-in per run) |
| JazzHR | *.applytojob.com/apply | `/apply/<id>/<slug>` (form on the page) | yes (opt-in per run) |

**Known ceiling:** companies on Recruitee, Teamtailor and Personio may serve the same form on their own domain (careers.company.com). Static matches cannot cover that; it is the generic any-site phase (optional host permissions).

**Terms reviewed:** none by the developer, same standing as all-platforms.md. Testing uses a dummy seeker only.
